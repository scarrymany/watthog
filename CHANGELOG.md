# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий следует [семантическому версионированию](https://semver.org/lang/ru/).

## [1.1.0] - 2026-08-09

### Добавлено

- **Оконный интерфейс** на customtkinter, отдельным исполняемым файлом без консоли:
  `WattHog-GUI.exe` для Windows и `watthog-gui-linux-x86_64` для Linux. Крупные текущие
  показания, разбивка по компонентам, график за всё время замера, прогноз расхода и
  настройки. Шкала, график и разбивка нарисованы вручную на Canvas, чтобы окно совпадало
  по виду с консольной версией.
- Команда `watthog gui` и точка входа `watthog-gui` для запуска окна.
- Пункты меню консольной версии: запуск оконного интерфейса и реквизиты поддержки.
- Возможность прервать замер снаружи: в окне это кнопка «Остановить», уже собранные
  выборки при этом не теряются и попадают в отчёт.
- Раздел поддержки проекта: [DONATE.md](DONATE.md), кнопка в окне с копированием адреса
  в буфер обмена, пункт консольного меню и разделы в обоих README.
- Снимки оконного интерфейса в документации, собираемые скриптом из настоящего замера.

### Изменено

- Палитра, форматирование величин и границы графика вынесены в общие модули
  `watthog/palette.py` и `watthog/formatting.py`: оконная версия больше не зависит от rich,
  а два интерфейса не могут разойтись по цветам и округлениям.
- Длинные имена железа сокращаются для компактных строк: "AMD Ryzen 7 7800X3D 8-Core
  Processor" превращается в "AMD Ryzen 7 7800X3D".
- Консольная сборка собирается без tkinter и customtkinter и потому осталась компактной.
  При попытке открыть в ней окно она подсказывает, какой файл скачать.

## [1.0.2] - 2026-08-09

### Исправлено

- Установщик для Windows теперь работает обоими способами. В 1.0.1 добавленный BOM
  починил запуск скачанного файла, но сломал документированную команду
  `irm ... | iex`: метка порядка байтов доезжает до строки и не даёт `param` быть
  первой инструкцией. Обе ловушки обходит только чистый ASCII без BOM, поэтому
  установщики переведены на английский текст. Интерфейс самой программы остался
  на русском.

### Добавлено

- Тест, запрещающий не-ASCII байты и BOM в обоих установщиках, чтобы эта пара
  ошибок не вернулась.

## [1.0.1] - 2026-08-09

### Исправлено

- `install.ps1` не запускался в Windows PowerShell 5.1. Файл лежал в UTF-8 без BOM,
  а этот интерпретатор читает такие скрипты в системной кодировке: кириллица в строках
  превращалась в мусор, и установка падала на разборе скрипта.

### Добавлено

- Тесты упаковки: кодировка обоих установщиков, отсутствие CRLF и BOM в `install.sh`,
  согласованность версии между пакетом, ресурсом исполняемого файла и историей изменений.

### Изменено

- Экшены GitHub Actions подняты до актуальных версий, чтобы уйти с устаревшего Node 20.
- Публикация релиза выполняется только по тегу: ручной запуск сборки больше не пытается
  создать релиз.

## [1.0.0] - 2026-08-09

Первый релиз.

### Добавлено

- Замер мощности всей системы с настраиваемой длительностью, по умолчанию 60 секунд.
- Прогноз расхода на час, 10 часов, 12 часов, сутки, неделю и месяц в киловатт-часах
  и в деньгах по заданному тарифу.
- Живая панель: текущая мощность, разбивка по компонентам, график за всё время замера,
  прогресс и оценка точности.
- Чтение реальной мощности видеокарт NVIDIA через NVML в Windows и Linux.
- Чтение реальной мощности видеокарт AMD и Intel через hwmon в Linux.
- Чтение реальной мощности процессора через RAPL в Linux, включая домен `psys`
  для всей платформы.
- Измерение потребления всей системы по мгновенной мощности разряда батареи на ноутбуках.
- Множитель частоты процессора из счётчика PDH `% Processor Performance` в Windows
  и из `base_frequency` в Linux.
- Загрузка видеокарт любого вендора из счётчика PDH `GPU Engine` с группировкой
  по адаптерам и типам движков.
- Модель мощности процессора, памяти, накопителей и платформы с калибровкой под
  прямое измерение, когда оно доступно.
- Кривая КПД блока питания вместо постоянного коэффициента.
- Справочник реальной мощности для 100 моделей процессоров и 60 моделей видеокарт
  плюс оценка по классу и числу ядер для всего остального.
- Распознавание встроенной графики и виртуальных адаптеров, чтобы не считать
  их мощность дважды.
- Меню, редактор настроек и справка по железу и источникам данных.
- Команды `run`, `info`, `config` и ключи командной строки для неинтерактивного запуска.
- Сохранение отчётов в JSON.
- Сборка в один исполняемый файл для Windows и Linux.
- Установщики одной командой: `install.ps1` для Windows и `install.sh` для Linux.
